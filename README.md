# Personal portfolio

A starter site for an architecture portfolio. HTML, CSS, and JavaScript, with Vite as the local development tool.

## Run locally

1. Open a terminal in this folder.
2. Install dependencies (only needed the first time, or after `package.json` changes):

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the URL Vite prints (usually `http://localhost:5173`) in your browser.

## Other commands

- `npm run build` — create a production build in `dist/`
- `npm run preview` — preview that production build locally
